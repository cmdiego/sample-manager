# TUI Legend

- White Block: Top display, container for different display views based on the current mode (MODE settings TBD)
  - Pink Block: Waveform display
- Orange Block: Logs/List/Enumeration of files
  - Red block: Filters Panel (Shows the selected filters, search commands, last query)
  - Green block: Main list display
- Blue Block: Session Summary, shows total selected songs, current MODE selected, total size of selection, target destination
- Purple Block: Show selected files list
